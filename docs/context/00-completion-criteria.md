## 1. 데이터 분석

- AI-Hub 이미지와 JSON 라벨 구조를 설명할 수 있다.
- VT와 RT 데이터를 구분할 수 있다.
- 클래스 목록과 클래스별 데이터 수를 확인할 수 있다.
- 이미지와 라벨 파일의 연결 상태를 검사할 수 있다.
- 잘못된 좌표, 누락 라벨, 손상 이미지를 확인할 수 있다.

## 2. 데이터 변환

- JSON Polygon 좌표를 이미지 위에 표시할 수 있다.
- Polygon 좌표에서 Bounding Box를 계산할 수 있다.
- AI-Hub 라벨을 YOLO Detection 형식으로 변환할 수 있다.
- AI-Hub 라벨을 YOLO Segmentation 형식으로 변환할 수 있다.
- Train, Validation, Test 데이터셋을 구성할 수 있다.

## 3. 모델 학습 및 추론

- 사전 학습된 YOLO 모델을 이용해 학습을 실행할 수 있다.
- 학습 결과 모델 파일을 저장할 수 있다.
- 새로운 이미지에 대해 추론할 수 있다.
- 예측한 클래스, Confidence, 위치를 확인할 수 있다.
- 예측 결과를 이미지로 저장할 수 있다.

## 4. 자동 라벨 생성

- 모델 예측 결과를 YOLO 라벨 파일로 저장할 수 있다.
- 자동 생성된 Bounding Box 또는 Polygon을 다시 시각화할 수 있다.
- Confidence 기준에 따라 저장할 예측 결과를 필터링할 수 있다.
- 생성된 라벨을 CVAT 또는 후속 시스템에서 사용할 수 있는 형태로 저장할 수 있다.

## 5. 성능 평가

- Precision, Recall, mAP50, mAP50-95를 확인할 수 있다.
- 클래스별 성능 차이를 확인할 수 있다.
- 정답 라벨과 예측 라벨을 비교할 수 있다.
- 오탐과 미탐 사례를 분류할 수 있다.
- 성능이 낮은 원인을 데이터, 라벨, 모델 관점에서 분석할 수 있다.

## 6. 1차 실험 범위

처음부터 모든 데이터와 모든 기능을 한 번에 다루지 않는다.

예시:

```
- 대상 데이터: AI-Hub RT 데이터
- 대상 클래스: 정상, 기공, 슬래그 혼입
- 1차 라벨 형식: Bounding Box
- 1차 모델: YOLO Detection
- 실험 목적: 데이터 변환, 학습, 추론, 자동 라벨 생성 가능 여부 확인
```

이후 2차 실험에서 범위를 확장한다.

```
- RT 전체 클래스
- Polygon 기반 Segmentation
- VT 데이터 적용
```

## 7. 기준 모델과 실험 조건

정확도 비교를 위해 기준선을 하나 정한다.

```
Baseline
- 사전 학습 YOLO 모델 사용
- 기본 이미지 크기 사용
- 기본 데이터 증강 사용
- 고정된 Train / Validation / Test 데이터셋 사용
- 동일한 평가 지표 사용
```

이후 실험에서는 한 번에 하나의 조건만 변경한다.

예:

- 데이터 수
- 이미지 크기
- Epoch
- Batch Size
- 증강 방식
- Confidence Threshold
- Detection과 Segmentation 방식

## 8. 실험 기록 항목

각 실험마다 아래 내용을 기록한다.

```
- 실험명
- 실험 목적
- 사용 데이터
- 대상 클래스
- 데이터 수
- 모델
- 이미지 크기
- Epoch
- Batch Size
- 주요 설정
- Precision
- Recall
- mAP50
- mAP50-95
- 오탐 사례
- 미탐 사례
- 결과 해석
- 다음 실험 계획
```

## 9. PoC 성공 기준

```
AI-Hub 원본 데이터
→ 데이터 구조 분석
→ 데이터 품질 및 라벨 검증
→ YOLO 형식 변환
→ Train / Validation / Test 구성
→ 모델 학습
→ 새로운 이미지 추론
→ 자동 라벨 파일 생성
→ 자동 라벨 시각화
→ 정답 라벨과 예측 라벨 비교
→ 성능 결과 분석 및 기록
```

다음 조건을 모두 충족해야 한다.

- 동일한 데이터와 설정으로 학습 및 추론 과정을 다시 실행할 수 있다.
- AI-Hub 원본 이미지와 JSON Polygon 라벨의 구조를 설명할 수 있다.
- 원본 JSON 라벨을 YOLO Detection 또는 Segmentation 형식으로 안정적으로 변환할 수 있다.
- 변환된 좌표와 클래스 정보가 원본 라벨과 일치하는지 검증할 수 있다.
- Train, Validation, Test 데이터셋을 동일한 기준으로 재구성할 수 있다.
- 학습된 모델로 새로운 이미지의 불량 유형과 위치를 예측할 수 있다.
- 모델 예측 결과를 자동 라벨 파일로 생성할 수 있다.
- 생성된 자동 라벨을 이미지 위에 다시 표시하거나 CVAT에서 확인할 수 있다.
- 정답 라벨과 자동 생성 라벨을 비교할 수 있다.
- Precision, Recall, mAP50, mAP50-95 등의 평가 결과를 해석할 수 있다.
- 클래스별 성능 차이와 주요 오탐·미탐 사례를 확인할 수 있다.
- 성능이 낮은 원인을 데이터, 라벨, 모델 설정 관점에서 설명할 수 있다.
- 각 실험의 조건과 결과가 기록되어 있어 이전 실험과 비교할 수 있다.
- MVP에서 사용할 데이터 변환, 모델 실행, 자동 라벨 생성 흐름이 확인된다.
