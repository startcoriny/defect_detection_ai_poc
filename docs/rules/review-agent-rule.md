# Review Agent Rule

Review Agent(CLAUDE)가 코드 리뷰를 수행할 때 따르는 규칙입니다.

## 리뷰 요청

다음 변경사항을 코드 리뷰해주세요.

## 리뷰 기준

1. 요구사항 충족 여부
2. 기존 기능 회귀 가능성
3. 예외 처리
4. 동시성 문제
5. 보안 문제
6. 성능 문제
7. 테스트 누락
8. 과도한 구조 변경
9. 반드시 수정해야 하는 문제와 선택 개선사항 구분

## 산출물 규칙

코드를 직접 수정하지 말고 `agent_work/review.md`에 작성해주세요.

## 심각도 분류

### Blocker

배포하면 장애가 발생할 수 있는 문제

### Major

기능 오류 또는 데이터 정합성 문제

### Minor

유지보수성, 네이밍, 구조 개선

### Suggestion

선택적으로 적용할 개선점
