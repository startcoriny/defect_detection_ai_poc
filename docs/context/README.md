# PoC 1단계 설계 문서 인덱스

이 폴더는 Python PoC(1단계, 용접 결함 검출 자동 라벨링)를 시작하기 전에 확정된 설계/기준 문서를 모아둔 곳이다.

아래 순서대로 읽으면 전체 그림을 잡기 쉽다.

## 1. [00-completion-criteria.md](00-completion-criteria.md)

1단계 전체를 완료했다고 판단하기 위한 최상위 기준 문서다.

데이터 분석, 데이터 변환, 모델 학습·추론, 자동 라벨 생성, 성능 평가 각 영역에서 "무엇을 할 수 있어야 하는가"를 나열하고, 1차 실험 범위(예시)와 PoC 성공 기준을 요약한다. 다른 문서들의 상위 요약본에 해당한다.

## 2. [01-experiment-scope.md](01-experiment-scope.md)

1차 PoC에서 실제로 다룰 데이터 범위를 확정한 문서다.

검사 유형(RT), 소재(AL), 대상 클래스(porosity, slag_inclusion), 목표 데이터 수(~300장), 라벨 형식(Polygon → Bounding Box), 데이터 분할 비율(7:1.5:1.5, Seed 42), 1차 PoC에서 제외하는 범위, 이후 확장 순서(2차~8차)를 담고 있다.

## 3. [02-task-list.md](02-task-list.md)

1단계를 구현하기 위한 26개 작업의 WBS(Work Breakdown Structure)다.

환경 구성 → 데이터 확보 → 구조 분석 → 품질 검사 → 클래스 표준화 → 변환 → 데이터셋 구성 → Baseline 학습 → 추론 → 자동 라벨 생성 → 평가 → 오탐/미탐 분석 → 문서화 순으로, 각 작업마다 수행 작업/산출물/완료 조건이 정의되어 있다. 작업 간 선행 관계와 전체 진행 상황표(30절)도 포함한다.

## 4. [03-deliverables.md](03-deliverables.md)

1단계가 끝났을 때 실제로 남아 있어야 하는 산출물 목록이다.

데이터/코드/설정·환경/모델·실험/평가·시각화/문서 6종으로 분류하고, 각 산출물의 파일 경로 예시와 완료 기준을 제시한다. 권장 최종 프로젝트 폴더 구조와 필수/선택 산출물 구분, 최종 완료 판정 체크리스트가 포함되어 있다.

## 5. [04-experiment-log-template.md](04-experiment-log-template.md)

개별 실험(예: Baseline, imgsz 변경 실험 등)을 기록할 때 사용하는 표준 양식이다.

실험 ID 규칙, 기준 실험 대비 변경 사항 기록법, 데이터셋/환경/학습 설정 표, 성능 결과표, 오탐·미탐 정성 평가 표, 자동 저장용 YAML 메타데이터 포맷, 실험 폴더 구조까지 포함되어 있다. 실제 실험을 수행할 때 이 양식을 복사해서 채워 넣는 용도다.
