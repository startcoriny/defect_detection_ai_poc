발표 중 "어떤 데이터로 학습했는가"를 보여줄 때 바로 열 수 있도록, 원본 위치에서 복사해온 파일이다(원본은 각각 `data/raw/`, `data/processed/dataset_v3/labels/test/`에 그대로 있고, 이 폴더의 파일은 발표 편의를 위한 복사본이라 두 곳 내용이 같아야 한다).

- `RT_AL_02_14488212.jpg` — 원본 이미지 (1280×720), `data/raw/steel/01.원천데이터/1. RTAL/`에서 복사

- `RT_AL_02_14488212.txt` — BBox 변환 + YOLO 정규화를 거친 최종 라벨(`3 0.522266 0.488194 0.057031 0.104167`), `data/processed/dataset_v3/labels/test/`에서 복사
