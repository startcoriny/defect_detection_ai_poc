## 1. 작업 목적

1단계에서는 설계만 확인하는 것이 아니라, AI-Hub 용접 데이터를 이용해 다음 전체 흐름을 실제 Python 코드로 구현한다.

```
원본 데이터 확보
→ 데이터 구조 분석
→ 데이터 품질 검사
→ Polygon 시각화
→ Bounding Box 변환
→ YOLO 데이터셋 생성
→ 데이터 분할
→ Baseline 학습
→ Test 추론
→ 자동 라벨 생성
→ 성능 평가
→ 오탐·미탐 분석
→ 결과 문서화
```

작업은 아래 순서대로 진행한다. 앞 작업의 완료 조건을 충족해야 다음 작업으로 넘어간다.

# 11. 작업 9. Polygon을 Bounding Box로 변환

## 수행 작업

각 Polygon에서 다음 값을 계산한다.

```
x_min = Polygon x 최솟값
y_min = Polygon y 최솟값
x_max = Polygon x 최댓값
y_max = Polygon y 최댓값
```

검증 항목:

- `x_min < x_max`
- `y_min < y_max`
- 박스가 이미지 범위 안에 있음
- Width와 Height가 0보다 큼
- 객체 수가 변환 전후 동일함
- 클래스가 유지됨

## 시각화

원본 Polygon과 변환 Bounding Box를 한 이미지에 함께 표시한다.

# 12. 작업 10. YOLO Detection 라벨 생성

## 수행 작업

Bounding Box를 YOLO 형식으로 변환한다.

```
class_id center_x center_y width height
```

정규화:

```
center_x /= image_width
center_y /= image_height
box_width /= image_width
box_height /= image_height
```

정상 이미지는 빈 라벨 파일로 처리한다.

## 파일 규칙

```
RT_AL_001.jpg
RT_AL_001.txt
```

- 정상 이미지 빈 라벨

## 완료 조건

- `( )` 모든 좌표가 `0~1` 범위다.
- `( )` 클래스 번호가 `0` 또는 `1`이다.
